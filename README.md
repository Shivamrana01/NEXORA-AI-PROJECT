# NEXORA – AI Website

NEXORA is a modern and futuristic website designed for technology and AI enthusiasts.

## Features
- Modern and attractive design
- Animated background
- Interactive chatbot demo
- Dark theme interface
- Mobile-friendly layout
- Quick question suggestions

## Technologies Used
- HTML
- CSS
- JavaScript

## About the Project
NEXORA helps users explore technology, learn programming, and get creative ideas through an interactive demo assistant.

**Note:** The chatbot currently uses predefined responses. Real AI integration can be added in the future.
